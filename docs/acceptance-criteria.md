# 受け入れ条件

人が手で全部試して、1 行ずつ合否を付けるためのもの。範囲は基本機能のみ。どの行も、確かめる工程を 2〜4 行で説明できる大きさにしている。
網羅は `docs/test-viewpoints.md` に置く。

## 試す前の準備

- 単位を始める前に、`sail artisan migrate:fresh --seed` で DB を入れ直す。この表の書籍名・ジャンル名・ユーザーは、シーダーのデータ（要件「シーディング」）。
- ログインは、シーダーのユーザー（パスワードはどれも `password`）で行う。書籍の作成者は、どれも山田太郎（`yamada@example.com`）。
- 同じ単位の中は、上から順に試す。前の行で作ったデータを使う行がある。
- ブラウザで試す。公開API（AC-15）の登録・更新・削除はブラウザだけでは送れないため、Postman などで送る。

「前提」の列は、その行が前提にしている確認事項（`docs/questions.md`）。回答が想定と違ったら、その行を直す。
