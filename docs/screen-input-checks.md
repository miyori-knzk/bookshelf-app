# 入力チェックとエラーメッセージ

入力画面ごとに、入力チェックの内容と、そのとき出すエラーメッセージをまとめたもの。
画面 ID は `docs/screen-list.md` の画面一覧と同じ。範囲は基本機能の画面（Web）のみ。公開API は画面が無いため含めない。

- チェックのルールは `docs/validation-rules.md`（想定）をもとにしている。ルールを変えるときは、`docs/validation-rules.md` を先に直し、このファイルを合わせる。
- エラーメッセージの文言は、要件「バリデーションメッセージ」で「自分で設計すること」とされているもの。どれも案で、文言の方針は Q-40（項目名を入れて、何を直せばよいかがわかる形）。
- 表の「Laravel のルール」は、そのメッセージを出すルール。

## 共通

| 項目                     | 内容                                                                                                                                                                       | 根拠                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| チェックする場所         | すべてサーバー側。どのフォームにも `novalidate` が付いており、ブラウザの入力チェックは働かない（SC-09 の評価に付いている `required` も働かない）                           | 各ビューの `<form ... novalidate>`           |
| エラー時の動き           | 入力した画面へ戻り、入力値を残したままエラーメッセージを表示する                                                                                                           | 各ビューの `old()`・`@error`・`x-input-error` |
| エラーの表示場所         | 各入力欄のすぐ下。画面上部にまとめて出す表示は無い                                                                                                                         | 各ビュー                                     |
| 1 項目に出す件数         | 書籍・ジャンル・レビューの画面は、最初の 1 件だけ（`@error` の `$message`）。ログイン・会員登録の画面は、その項目のエラーをすべて（`x-input-error` が `$errors->get()` を一覧表示） | `books/_form` など、`components/input-error` |
| メッセージを定義する場所 | 書籍・ジャンル・レビューは各 FormRequest の `messages()`（Q-40）。会員登録・ログインは `lang/ja/validation.php` と `lang/ja/auth.php`（Q-42）                               | `docs/validation-rules.md`「エラーメッセージ」 |

「文字列」のチェック（`string`）と「配列」のチェック（`array`）は、画面を普通に操作しているかぎり失敗しない（入力欄の値は必ず文字列、ジャンルのチェックボックスは必ず配列で送られるため）。開発者ツールなどで送信内容を書き換えたときのためのチェックで、メッセージも用意しておく。

## SC-03 書籍登録・SC-04 書籍編集

FormRequest：登録 `StoreBookRequest`、編集 `UpdateBookRequest`（名前は案）。ルールは `docs/validation-rules.md`「書籍登録・書籍編集（Web）」、確認事項は Q-11。

| 項目     | 入力名           | チェック内容               | Laravel のルール | エラーメッセージ（案）                     | 表示場所（`_form`） |
| -------- | ---------------- | -------------------------- | ---------------- | ------------------------------------------ | ------------------- |
| タイトル | `title`          | 入力されている             | `required`       | タイトルは必須です。                       | タイトル欄の下      |
|          |                  | 文字列                     | `string`         | タイトルは文字列で入力してください。       | 同上                |
|          |                  | 255 文字以内               | `max:255`        | タイトルは255文字以内で入力してください。  | 同上                |
| 著者     | `author`         | 入力されている             | `required`       | 著者は必須です。                           | 著者欄の下          |
|          |                  | 文字列                     | `string`         | 著者は文字列で入力してください。           | 同上                |
|          |                  | 255 文字以内               | `max:255`        | 著者は255文字以内で入力してください。      | 同上                |
| ISBN     | `isbn`           | 入力されている             | `required`       | ISBNは必須です。                           | ISBN-13 欄の下      |
|          |                  | ハイフン無しの数字 13 桁   | `digits:13`      | ISBNは13桁の数字で入力してください。       | 同上                |
|          |                  | ほかの書籍と重ならない     | `unique:books,isbn`（編集は自分を除く） | このISBNはすでに登録されています。 | 同上          |
| 出版日   | `published_date` | 入力されている             | `required`       | 出版日は必須です。                         | 出版日欄の下        |
|          |                  | `YYYY-MM-DD` 形式の正しい日付 | `date_format:Y-m-d` | 出版日は正しい日付で入力してください。  | 同上                |
| 説明     | `description`    | 文字列（任意）             | `string`         | 説明は文字列で入力してください。           | 説明欄の下          |
|          |                  | 16000 文字以内             | `max:16000`      | 説明は16000文字以内で入力してください。    | 同上                |
| 画像URL  | `image_url`      | URL の形式（任意）         | `url`            | 画像URLはURLの形式で入力してください。     | 画像URL欄の下       |
|          |                  | 255 文字以内               | `max:255`        | 画像URLは255文字以内で入力してください。   | 同上                |
| ジャンル | `genres`         | 1 つ以上選択されている     | `required`・`min:1` | ジャンルを1つ以上選択してください。     | ジャンル欄の下（`@error('genres')`） |
|          |                  | 配列                       | `array`          | ジャンルの選択内容が正しくありません。     | 同上                |
|          | `genres.*`       | 整数                       | `integer`        | 選択したジャンルが正しくありません。       | ジャンル欄の下（`@error('genres.*')`） |
|          |                  | 存在するジャンル           | `exists:genres,id` | 選択したジャンルは存在しません。         | 同上                |

- 説明・画像URLは任意（`nullable`）。空のときはチェックしない。
- `required` と `min:1` は同じメッセージにする。どちらも「1 つも選んでいない」ときに失敗するため。
- 出版日は `date` 入力欄のため、ブラウザによっては正しくない日付を入力できないが、サーバー側でもチェックする。

## SC-02 書籍詳細（レビュー投稿）・SC-09 レビュー編集

FormRequest：投稿 `StoreReviewRequest`、編集 `UpdateReviewRequest`（名前は案）。ルールは `docs/validation-rules.md`「レビュー投稿・レビュー編集」、確認事項は Q-21。

| 項目     | 入力名    | チェック内容         | Laravel のルール | エラーメッセージ（案）                       | 表示場所                         |
| -------- | --------- | -------------------- | ---------------- | -------------------------------------------- | -------------------------------- |
| 評価     | `rating`  | 選択されている       | `required`       | 評価を選択してください。                     | SC-02：評価の下、SC-09：★の下    |
|          |           | 整数                 | `integer`        | 評価は1〜5の中から選択してください。         | 同上                             |
|          |           | 1〜5                 | `between:1,5`    | 評価は1〜5の中から選択してください。         | 同上                             |
| コメント | `comment` | 入力されている       | `required`       | コメントを入力してください。                 | コメント欄の下                   |
|          |           | 文字列               | `string`         | コメントは文字列で入力してください。         | 同上                             |
|          |           | 1000 文字以内        | `max:1000`       | コメントは1000文字以内で入力してください。   | 同上                             |

- 評価は選択式のため、`integer` と `between` は同じメッセージにする（どちらも「選択肢に無い値が送られた」とき）。
- コメントは必須（Q-21）。提供ビューのコメント欄に必須マークは無い。
- 「選択してください」の動詞は、SC-02 がプルダウン、SC-09 がラジオボタンで、どちらにも合う。

## SC-13 会員登録

Fortify の `app/Actions/Fortify/CreateNewUser.php` でチェックする（Q-36）。ルールは `docs/validation-rules.md`「会員登録（Fortify）」、パスワードの条件の確認事項は Q-09。
メッセージは `lang/ja/validation.php` に書く（Q-42）。項目名は `attributes` に「お名前」「メールアドレス」「パスワード」を登録し、`:attribute` に入れる。

| 項目           | 入力名     | チェック内容                 | Laravel のルール | エラーメッセージ（案）                           | 表示場所             |
| -------------- | ---------- | ---------------------------- | ---------------- | ------------------------------------------------ | -------------------- |
| お名前         | `name`     | 入力されている               | `required`       | お名前は必須です。                               | お名前欄の下         |
|                |            | 文字列                       | `string`         | お名前は文字列で入力してください。               | 同上                 |
|                |            | 255 文字以内                 | `max:255`        | お名前は255文字以内で入力してください。          | 同上                 |
| メールアドレス | `email`    | 入力されている               | `required`       | メールアドレスは必須です。                       | メールアドレス欄の下 |
|                |            | 文字列                       | `string`         | メールアドレスは文字列で入力してください。       | 同上                 |
|                |            | メールアドレスの形式         | `email`          | メールアドレスは正しい形式で入力してください。   | 同上                 |
|                |            | 255 文字以内                 | `max:255`        | メールアドレスは255文字以内で入力してください。  | 同上                 |
|                |            | ほかのユーザーと重ならない   | `unique:users`   | このメールアドレスはすでに登録されています。     | 同上                 |
| パスワード     | `password` | 入力されている               | `required`       | パスワードは必須です。                           | パスワード欄の下     |
|                |            | 文字列                       | `string`         | パスワードは文字列で入力してください。           | 同上                 |
|                |            | 8 文字以上                   | Fortify の `PasswordValidationRules` | パスワードは8文字以上で入力してください。 | 同上           |
|                |            | パスワード確認と一致         | `confirmed`      | パスワードとパスワード確認が一致しません。       | 同上                 |

- 「このメールアドレスはすでに登録されています。」は `:attribute` の形では書けないため、`lang/ja/validation.php` の `custom`（`email.unique`）に書く。
- `confirmed` のエラーは、Laravel の仕組み上 `password` に付く。そのため、パスワード確認欄の下（`register` 30 行目の `x-input-error`）には何も表示されない。
- 「8 文字以上」は、Fortify の `PasswordValidationRules` が使う Laravel の `Password` ルールが判定し、メッセージは `lang/ja/validation.php` の `min.string` に書く（Fortify v1.36.2 で確認、Q-39）。
- 会員登録の画面の入力欄は 1 項目に複数のエラーを表示できる（「共通」参照）。ただし、Laravel は `required` で失敗した項目の残りのチェックを行わないため、空欄で「必須です」とほかのメッセージが並ぶことは無い。

## SC-12 ログイン

Fortify 本体の `LoginRequest` がチェックする。ルールは `docs/validation-rules.md`「ログイン（Fortify）」、確認事項は Q-42。

| 項目           | 入力名     | チェック内容                         | Laravel のルール・キー | エラーメッセージ（案）                                         | 表示場所             |
| -------------- | ---------- | ------------------------------------ | ---------------------- | -------------------------------------------------------------- | -------------------- |
| メールアドレス | `email`    | 入力されている                       | `required`             | メールアドレスは必須です。                                     | メールアドレス欄の下 |
|                |            | 文字列                               | `string`               | メールアドレスは文字列で入力してください。                     | 同上                 |
| パスワード     | `password` | 入力されている                       | `required`             | パスワードは必須です。                                         | パスワード欄の下     |
|                |            | 文字列                               | `string`               | パスワードは文字列で入力してください。                         | 同上                 |
| （認証）       | －         | メールアドレスとパスワードが合う     | `auth.failed`          | メールアドレスまたはパスワードが正しくありません。             | メールアドレス欄の下 |

- 認証のエラーは、Fortify がメールアドレス（`email`）の項目に付けるため、メールアドレス欄の下に出る。
- ログインのメールアドレスは、形式（`email` ルール）を確かめない。形式が違う入力は、認証で「合わない」になる。会員登録（SC-13）は形式を確かめる。
- `auth.failed` は、メールアドレスとパスワードのどちらが違うかを書かない（登録済みのメールアドレスかどうかを知られないため）。
- ログインの回数制限は 1 分に 5 回（メールアドレスと IP の組み合わせごと。成功した回も数える。Fortify の初期値、Q-60）。超えると入力チェックの前に止まり、メッセージではなく標準のエラー画面（429）になる（`docs/error-handling.md`）。

## 画面上部のエラーメッセージ

入力欄に付かないエラー。ビューで表示できる場所は SC-05 ジャンル一覧の `session('error')`（`genres/index.blade.php` 22〜26 行目）だけ。

| 画面  | 状況                                      | エラーメッセージ（案）                               | 確認事項   |
| ----- | ----------------------------------------- | ---------------------------------------------------- | ---------- |
| SC-05 | 書籍が紐付いているジャンルを削除しようとした | 書籍が登録されているジャンルは削除できません。     | Q-17・Q-40 |

ほかの画面には `session('error')` の表示場所が無いため、画面上部のエラーメッセージは使わない。
