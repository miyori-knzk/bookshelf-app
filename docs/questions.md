# 確認事項リスト

`docs/requirements.md`（以下「要件」）と `resources/views/` 配下のビュー（以下「ビュー」）を突き合わせて出てきた確認事項。
どれもこちらの想定を添えている。回答が出るまでは、この想定で設計を進める。
範囲は基本機能のみ（`docs/features.md` 参照）。
具体的なバリデーションルールは `docs/validation-rules.md` にまとめ、各ルールから対応する確認事項（Q-xx）を参照できるようにしている。

状態欄には次のいずれかを書く。空欄はまだ回答が無いもの。

### Q-27 レスポンス JSON の案

想定の内容は次のとおり。

- 書籍 1 件の項目は `id`・`title`・`author`・`isbn`・`published_date`・`description`・`image_url`・`user`・`genres`・`created_at`・`updated_at`
- `user` は作成者の `id` と `name` だけを返し、メールアドレスは返さない
- `published_date` は `YYYY-MM-DD`、`created_at`・`updated_at` は ISO 8601 形式
- `description`・`image_url` は未入力なら `null`
- 一覧は Laravel 標準のページ分け形式（`data`・`links`・`meta`）

#### 書籍一覧 `GET /api/v1/books`（200）

```json
{
  "data": [
    {
      "id": 12,
      "title": "サンプル書籍",
      "author": "山田 太郎",
      "isbn": "9784000000000",
      "published_date": "2024-04-01",
      "description": "書籍の説明文",
      "image_url": "https://example.com/image.jpg",
      "user": { "id": 3, "name": "山田 花子" },
      "genres": [
        { "id": 1, "name": "小説" },
        { "id": 4, "name": "ミステリー" }
      ],
      "created_at": "2026-10-30T10:15:00.000000Z",
      "updated_at": "2026-10-30T10:15:00.000000Z"
    }
  ],
  "links": {
    "first": "http://localhost/api/v1/books?page=1",
    "last": "http://localhost/api/v1/books?page=3",
    "prev": null,
    "next": "http://localhost/api/v1/books?page=2"
  },
  "meta": {
    "current_page": 1,
    "from": 1,
    "last_page": 3,
    "links": [],
    "path": "http://localhost/api/v1/books",
    "per_page": 10,
    "to": 10,
    "total": 25
  }
}
```

`meta.links` には、ページ番号のリンクの一覧が入る（Laravel 標準。ここでは省略）。

#### 書籍登録・更新・削除

| 操作                            | ステータス | 本文                       |
| ------------------------------- | ---------- | -------------------------- |
| 登録 `POST /api/v1/books`       | 201        | 登録した書籍（詳細と同じ形） |
| 更新 `PUT /api/v1/books/{book}` | 200        | 更新後の書籍（詳細と同じ形） |
| 削除 `DELETE /api/v1/books/{book}` | 204     | なし                       |

入力チェックのエラー時（422）は Q-28 の想定どおり Laravel 標準の形（`message` と `errors`）で返す。
