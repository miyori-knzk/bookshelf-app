# 公開API 仕様

外部アプリ向けの公開API（JSON）の、エンドポイント・入力・出力・エラーをまとめたもの。範囲は基本機能のみ（認証なし）。
ルートは `docs/routing.md`、入力チェックのルールは `docs/validation-rules.md` を参照。

- レスポンスの項目は Q-57・Q-58-1〜Q-58-5、一覧の件数と並び順は Q-27、入力チェックは Q-28・Q-41・Q-43、登録者は Q-26 の想定。
- ★応用機能で、書き込み系（POST・PUT・DELETE）に Sanctum のトークン認証と `BookPolicy` を付ける。この仕様書には含めない。

## 共通

| 項目               | 内容                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------ |
| ベース URL         | `http://localhost/api/v1`（開発環境）                                                      |
| 認証               | なし                                                                                       |
| リクエストの形式   | POST・PUT の本文は JSON（`Content-Type: application/json`）                                |
| レスポンスの形式   | JSON（`Content-Type: application/json`）。エラーも JSON で返す（`docs/error-handling.md`） |
| 文字コード         | UTF-8                                                                                      |
| 回数の制限         | 1 分に 60 回まで（IP ごと。Laravel の初期値）。超えると 429                               |
| レスポンスの作り方 | API Resource（`BookResource`、名前は案）                                                    |

リクエストには `Accept: application/json` を付けることを勧める。付けなくても JSON で返す（`docs/error-handling.md`「公開API は必ず JSON で返す」）。

### 書籍オブジェクト

どのエンドポイントも、書籍は次の形で返す。

| 項目             | 型             | 内容                                                         |
| ---------------- | -------------- | ------------------------------------------------------------ |
| `id`             | 整数           | 書籍 ID                                                      |
| `title`          | 文字列         | タイトル                                                     |
| `author`         | 文字列         | 著者                                                         |
| `isbn`           | 文字列         | ISBN（ハイフン無しの 13 桁）                                 |
| `published_date` | 文字列         | 出版日（`YYYY-MM-DD`）                                       |
| `description`    | 文字列 / null  | 説明。未入力なら `null`                                      |
| `image_url`      | 文字列 / null  | 画像URL。未入力なら `null`                                   |
| `user`           | オブジェクト   | 登録者。`id` と `name` だけ（メールアドレスは返さない）      |
| `genres`         | 配列           | 紐付いているジャンル。各要素は `id` と `name`                |
| `created_at`     | 文字列         | 登録日時（ISO 8601、UTC）                                    |
| `updated_at`     | 文字列         | 更新日時（ISO 8601、UTC）                                    |

書籍一覧（F-21）の各書籍と書籍詳細（F-22）には、次の項目を足す。

| 項目                 | 型            | 内容                                                                       |
| -------------------- | ------------- | -------------------------------------------------------------------------- |
| `reviews_avg_rating` | 数値 / null   | 平均評価。小数第 1 位に丸める（`books/index` の表示と同じ。Q-58-1）。レビューが無ければ `null` |
| `reviews_count`      | 整数          | レビュー件数。レビューが無ければ 0                                         |

書籍詳細（F-22）には、さらに次の項目を足す。

| 項目      | 型   | 内容                                         |
| --------- | ---- | -------------------------------------------- |
| `reviews` | 配列 | レビュー。新しい順（Q-14）。レビューが無ければ空の配列 |

`reviews` の各要素は次の形。

| 項目         | 型            | 内容                                                    |
| ------------ | ------------- | ------------------------------------------------------- |
| `id`         | 整数          | レビュー ID                                             |
| `rating`     | 整数          | 評価（1〜5）                                            |
| `comment`    | 文字列        | コメント                                                |
| `user`       | オブジェクト  | 投稿者。`id` と `name` だけ（メールアドレスは返さない） |
| `created_at` | 文字列        | 投稿日時（ISO 8601、UTC）                               |

書籍登録・書籍更新（F-23・F-24）は、書籍詳細と同じ形で返す（Q-57）。

`isbn` は数字だけだが、先頭の 0 が消えないよう文字列で返す。

## エンドポイント一覧

| メソッド | パス            | 説明               | 成功時 | 機能 |
| -------- | --------------- | ------------------ | ------ | ---- |
| GET      | `/books`        | 書籍一覧を取得する | 200    | F-21 |
| GET      | `/books/{book}` | 書籍詳細を取得する | 200    | F-22 |
| POST     | `/books`        | 書籍を新規登録する | 201    | F-23 |
| PUT      | `/books/{book}` | 書籍を更新する     | 200    | F-24 |
| DELETE   | `/books/{book}` | 書籍を削除する     | 204    | F-25 |

## GET /books　書籍一覧（F-21）

### 入力（クエリ文字列）

すべて任意。

| 名前       | 型     | 内容                                                         | ルール                          |
| ---------- | ------ | ------------------------------------------------------------ | ------------------------------- |
| `keyword`  | 文字列 | タイトルか著者に、この文字列を含む書籍に絞る（部分一致）     | 255 文字以内                    |
| `genre_id` | 整数   | このジャンルが紐付いている書籍に絞る                         | 存在するジャンルの ID           |
| `page`     | 整数   | ページ番号。指定が無ければ 1                                 | 1 以上                          |
| `per_page` | 整数   | 1 ページの件数。指定が無ければ 20（Q-27）                    | 1〜100                          |

- `keyword` と `genre_id` を両方指定したときは、両方に当てはまる書籍に絞る（Q-55）。
- `keyword` に含まれる `%` と `_` は、ワイルドカードではなく普通の文字として検索する（Q-55）。
- 並び順は登録日時（`created_at`）の新しい順（Q-27）。
- 空の値（`?keyword=`）は、指定しなかったのと同じ扱い。

### 出力（200）

## POST /books　書籍登録（F-23）

### 入力（JSON 本文）

| 名前             | 型            | 必須 | ルール                                         |
| ---------------- | ------------- | ---- | ---------------------------------------------- |
| `user_id`        | 整数          | ○    | 存在するユーザーの ID。登録者として保存する（Q-26） |
| `title`          | 文字列        | ○    | 255 文字以内                                   |
| `author`         | 文字列        | ○    | 255 文字以内                                   |
| `isbn`           | 文字列        | ○    | ハイフン無しの数字 13 桁。ほかの書籍と重ならない |
| `published_date` | 文字列        | ○    | 日付（`YYYY-MM-DD`）                           |
| `description`    | 文字列 / null |      | 2000 文字以内                                  |
| `image_url`      | 文字列 / null |      | URL の形式・255 文字以内                       |
| `genres`         | 整数の配列    | ○    | 1 つ以上。どれも存在するジャンルの ID          |

ルールは Web の書籍登録と同じ（Q-28）。`genres` は、出力ではオブジェクトの配列だが、入力ではジャンル ID の配列。

例：

```json
{
  "user_id": 2,
  "title": "リーダブルコード",
  "author": "Dustin Boswell",
  "isbn": "9784873115659",
  "published_date": "2012-06-23",
  "description": null,
  "image_url": null,
  "genres": [3]
}
```

### 出力（201）

登録した書籍を、書籍詳細と同じ形で返す（Q-57）。

```json
{
  "data": {
    "id": 12,
    "title": "リーダブルコード",
    "author": "Dustin Boswell",
    "isbn": "9784873115659",
    "published_date": "2012-06-23",
    "description": null,

      { "id": 3, "name": "技術書" }
    ],
    "reviews_avg_rating": null,
    "reviews_count": 0,
    "reviews": [],
    "created_at": "2026-11-01T03:20:00.000000Z",
    "updated_at": "2026-11-01T03:20:00.000000Z"
  }
}
```

| ステータス | 場合                                         |
| ---------- | -------------------------------------------- |
| 422        | 入力がルールに合わない（ISBN の重なりを含む） |

## PUT /books/{book}　書籍更新（F-24）

### 入力

パスの `book` に書籍 ID を入れ、本文は書籍登録と同じ。`user_id` だけ任意。

- 登録と同じく、`user_id` 以外のすべての項目を送る（送らなかった必須の項目は 422 になる）。
- `user_id` を送ったときは、存在するユーザーの ID かを検証し、登録者を変更する。送らなければ変えない（Q-41）。
- ISBN の重なりのチェックでは、その書籍自身を除く。
- `genres` は、送ったジャンルに入れ替える（外したジャンルの紐付けは消える）。

例：`PUT /api/v1/books/12`

```json
{
  "title": "リーダブルコード",
  "author": "Dustin Boswell, Trevor Foucher",
  "isbn": "9784873115658",
  "published_date": "2012-06-23",
  "description": "より良いコードを書くためのシンプルで実践的なテクニック。",
  "image_url": null,
  "genres": [3, 2]
}
```

### 出力（200）

更新後の書籍を、書籍詳細と同じ形で返す（Q-57）。

```json
{
  "data": {
    "id": 12,
    "title": "リーダブルコード",
    "author": "Dustin Boswell, Trevor Foucher",
    "isbn": "9784873115658",
    "published_date": "2012-06-23",
    "description": "より良いコードを書くためのシンプルで実践的なテクニック。",
    "image_url": null,
    "user": { "id": 2, "name": "鈴木花子" },
    "genres": [
      { "id": 2, "name": "ビジネス" },
      { "id": 3, "name": "技術書" }
    ],
    "reviews_avg_rating": null,
    "reviews_count": 0,
    "reviews": [],
    "created_at": "2026-11-01T03:20:00.000000Z",
    "updated_at": "2026-11-01T04:05:00.000000Z"
  }
}
```

この例の ISBN `9784873115658` は、シーダーの 3 冊目（リーダブルコード）と同じ。シーダーのデータが入っている DB では 422 になる。

### エラー

| ステータス | 場合                                         |
| ---------- | -------------------------------------------- |
| 404        | その ID の書籍が無い                         |
| 422        | 入力がルールに合わない（ISBN の重なりを含む） |

## DELETE /books/{book}　書籍削除（F-25）

### 入力

| 名前   | 場所 | 内容    |
| ------ | ---- | ------- |

### 出力（204）

本文なし。その書籍のジャンルの紐付け・お気に入り・レビューと、そのレビューへのいいねも一緒に消える（Q-12）。

### エラー

| ステータス | 場合                 |
| ---------- | -------------------- |
| 404        | その ID の書籍が無い |

## エラーの返し方

### 本文の形

どのエラーも `message` を返す。入力エラー（422）だけ、項目ごとのメッセージを `errors` に入れる。

| ステータス | 場合                                       | 本文                    |
| ---------- | ------------------------------------------ | ----------------------- |
| 404        | その ID の書籍が無い、または無いパス       | `message`               |
| 405        | パスはあるが、メソッドが違う               | `message`               |
| 422        | 入力がルールに合わない                     | `message`・`errors`     |
| 429        | 回数の制限を超えた                         | `message`               |
| 500        | サーバーの中で予期しないエラーが起きた     | `message`               |

それぞれのメッセージの文言と、詳細を返さない理由は `docs/error-handling.md` を参照。

### 422 の例

`POST /api/v1/books` に、タイトル無し・ISBN 12 桁・存在しないユーザーを送ったとき。

```json
{
  "message": "登録者が存在しません。 (and 2 more errors)",
  "errors": {
    "user_id": ["登録者が存在しません。"],
    "title": ["タイトルは必須です。"],
    "isbn": ["ISBNは13桁の数字で入力してください。"]
  }
}
```

- `errors` は項目ごとの配列。1 つの項目にエラーが複数あれば、すべて入る（Web の画面は最初の 1 件だけを表示するが、API は全件を返す）。
- `message` は、最初のエラーと、残りの件数。最初のエラーは、FormRequest の `rules()` に書いた順で最初に失敗した項目のもの。
- 残りの件数の部分（`(and 2 more errors)`）は Laravel 標準では英語。`lang/ja.json` に訳を足して日本語にする（Q-53）。上の例は、訳の文言が決まっていないため英語のまま載せている。
- `genres.*` のエラーは、`genres.0`・`genres.1` のように、何番目の要素かが付いた名前で入る。

### 404 の例

```json
{
  "message": "書籍が見つかりません。"
}
```

## 入力エラーのメッセージ

書籍の項目（`title`〜`genres.*`）のメッセージは、Web と同じ（`docs/screen-input-checks.md`「SC-03 書籍登録・SC-04 書籍編集」）。
公開API だけにある項目のメッセージは次のとおり。どれも案（文言の方針は Q-40）。

| 項目             | 入力名     | Laravel のルール       | エラーメッセージ（案）                          |
| ---------------- | ---------- | ---------------------- | ----------------------------------------------- |
| 登録者ID         | `user_id`  | `required`（登録のみ） | 登録者IDは必須です。                            |
|                  |            | `integer`              | 登録者IDは整数で指定してください。              |
|                  |            | `exists:users,id`      | 登録者が存在しません。                          |
| キーワード       | `keyword`  | `string`               | キーワードは文字列で指定してください。          |
|                  |            | `max:255`              | キーワードは255文字以内で指定してください。     |
| ジャンルID       | `genre_id` | `integer`              | ジャンルIDは整数で指定してください。            |
|                  |            | `exists:genres,id`     | 指定したジャンルは存在しません。                |
| ページ番号       | `page`     | `integer`              | ページ番号は整数で指定してください。            |
|                  |            | `min:1`                | ページ番号は1以上で指定してください。           |
| ページあたり件数 | `per_page` | `integer`              | ページあたり件数は整数で指定してください。      |
|                  |            | `between:1,100`        | ページあたり件数は1〜100で指定してください。    |

画面が無いため、「入力してください」ではなく「指定してください」にしている。
